## Summary
# Deep Learning

## Direct Answer
Deep learning is a subset of machine learning that uses **artificial neural networks with multiple layers** (hence "deep") to automatically learn hierarchical representations and patterns from large amounts of data.

---

## Key Facts

- **Part of the AI hierarchy:** Artificial Intelligence → Machine Learning → Deep Learning
- **Core structure:** Built on **artificial neural networks (ANNs)** inspired by the human brain's interconnected neurons
- **"Deep" meaning:** Refers to the many **hidden layers** between input and output — typically dozens to hundreds of layers
- **Automatic feature extraction:** Unlike traditional ML, deep learning learns features directly from raw data without manual feature engineering
- **Data & compute hungry:** Requires large datasets and significant computational power (GPUs/TPUs)
- **Training method:** Uses **backpropagation** and **gradient descent** to optimize model weights

---

## Key Subtopics

### Common Architectures
| Architecture | Common Use Case |
|---|---|
| CNN (Convolutional Neural Network) | Image recognition, computer vision |
| RNN / LSTM | Sequential data, time series, language |
| Transformer | NLP, [[Large Language Models]] (LLMs) |
| GAN (Generative Adversarial Network) | Image/content generation |

### Popular Applications
- 🖼️ **Computer Vision** — facial recognition, medical imaging
- 🗣️ **Natural Language Processing** — chatbots, translation, text generation
- 🎵 **Audio/Speech** — voice assistants, speech-to-text
- 🎮 **Reinforcement Learning** — game playing (AlphaGo), robotics

### Key Advantages
- Handles **unstructured data** (images, text, audio) effectively
- Scales well with more data and compute
- Achieves **state-of-the-art** performance on many benchmarks

### Limitations
- Requires **large labeled datasets**
- Computationally **expensive** to train
- Often acts as a **"black box"** (low interpretability)
- Prone to **overfitting** without proper regularization

---

## Notable Frameworks
- **TensorFlow** (Google)
- **PyTorch** (Meta)
- **Keras** (high-level API)

---

> **In short:** Deep learning powers most modern AI breakthroughs — from ChatGPT to self-driving cars — by using layered neural networks to learn complex patterns directly from raw data.
